
# RecipeIQ: Personalized Recipe Recommendation System

RecipeIQ is an AI-powered recipe recommendation and analytics
project built using the Food.com recipe dataset. It uses Neural
Collaborative Filtering (NCF) to rank recipes for users based on
learned user and recipe embeddings.

The project covers the end-to-end machine learning workflow,
including data preprocessing, feature engineering, interaction
data preparation, model training, ranking evaluation, and
deployment through a Streamlit web application.

## Problem Statement

Recipe platforms contain large collections of recipes, making it
difficult for users to discover options relevant to their
preferences. RecipeIQ explores how collaborative filtering can
be used to rank recipes for individual users and provide an
interactive recommendation experience.

The project also compares the trained NCF model with a
popularity-based baseline to evaluate its ranking performance.

## Project Objectives

- Prepare and audit recipe and user-interaction data.
- Build a Neural Collaborative Filtering recommendation model.
- Evaluate recommendations using ranking metrics.
- Compare the NCF model against a popularity baseline.
- Develop a Streamlit interface for generating and exploring
  recipe recommendations.
- Document model performance, limitations, and possible
  improvements.
